## 1. Что за проект

Flutter-приложение (собирается под веб) с нижним меню из двух вкладок:
**Supabase** и **Firebase**. Вкладки независимы: у каждой своя
авторизация и своя база данных.

На обеих вкладках пять способов входа: логин/почта + пароль, Google,
GitHub, Яндекс, ВКонтакте. После входа показываются **имя, роль,
список пользователей из базы и кнопка «Выйти»**. Список сортируется
по столбцу, удалять записи может только администратор.

Это лабораторная работа студентки. Задания выдаёт преподаватель.

   На Pages работает, но на localhost и Firebase Hosting вход через

3. **Удаление администратором на вкладке Firebase** не проверялось

## 6. Грабли — чтобы не повторять

- **Сообщения об ошибках врут о причине.** `Security Error` у ВК значил
  «не тот протокол», «кнопка Google не грузится» — «запущено не по тому
  адресу». Не гадать: открывать адрес авторизации руками, смотреть
  консоль браузера, проверять `curl`.
- **Supabase при запрете удаления отвечает `HTTP 204`**, как будто всё
  прошло, но удаляет ноль строк. Проверять надо данные, а не код ответа.
  Firebase в том же случае честно говорит `Permission denied`.
- **Два разных приложения GitHub** — для Supabase и для Firebase,
  у них разные адреса возврата. Секреты путать нельзя.
- **Firebase медленнее Supabase примерно в 8 раз** (~1000 мс против
  ~120 мс): база в регионе `us-central1`. Это не баг.
- **Supabase молча уводит на Site URL**, если запрошенный адрес
  возврата не совпадает со списком Redirect URLs.
- **У ассистента нет прав публиковать** (`firebase deploy` блокируется
  защитой) и вставлять секреты в поля — это делает владелица сама.
- **Расширение Chrome регулярно отваливалось.** Если браузер не
  отвечает — часть настроек Firebase можно сделать через CLI
  (`firebase deploy --only database`, `firebase database:set`),
  он установлен и авторизован.
- **SQL Editor в Supabase** показывает диалог «Potential issue detected»
  на запросы с `drop` — надо подтвердить кнопкой «Run query».

## 8. Структура кода

```
lib/
  main.dart              запуск, подключение сервисов, нижнее меню
  ui_kit.dart            общие виджеты обеих вкладок (экран входа, таблица)
  supabase_tab.dart      вкладка Supabase
  firebase_tab.dart      вкладка Firebase
  social_oauth.dart      вход через ВК и Яндекс вручную
  oauth_window_web.dart  окно входа — браузер (BroadcastChannel)
  oauth_window_io.dart   окно входа — телефон
  firebase_options.dart  ключи Firebase (создан flutterfire)
web/auth.html            страница возврата для ВК и Яндекса
db/                      SQL и правила баз
.github/workflows/       сборка APK и публикация на Pages
```

## 9. Как общаться с владелицей

- Пишет по-русски, отвечать по-русски.
- Учится: объяснять **почему** так сделано, а не только что сделано.
- Просит в конце работы делать коммит и пуш в репозиторий.
- Работу проверяет на выложенной версии, поэтому после изменений кода
  нужен либо `git push` (для Pages), либо `firebase deploy` (для Hosting,
  запускает она сама).
